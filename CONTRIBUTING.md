# Contributing

Mynota is a small, personal fork of [Myna](https://github.com/fmflurry/myna), open source under the MIT license. You are free to fork it and do what you like with it.

If you want to propose a change here:

- Open a pull request. Nothing is pushed to the main branches directly, except by the maintainer.
- Issues and pull requests are read and handled when the maintainer has time. There is no response delay and no promise to merge. A small, focused change with a clear reason has the best chance.
- The scope is deliberately narrow (see the [README](README.md)). Features that belong to the original Myna are better proposed there.
- Run the checks that apply before you open the pull request: the commands are in [CLAUDE.md](CLAUDE.md) and [docs/windows-recipe.md](docs/windows-recipe.md).

Bugs found while testing a beta are welcome as issues: say the Windows version, the audio setup (wired, USB or Bluetooth headset) and what you expected.
